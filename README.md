# 🌽 Junina Byte

Este repositório contém o **Junina Byte**, um site temático de festa junina com vibe tech, feito em **React** com **Vite**.

---

## 📋 Descrição

**Junina Byte** busca trazer a alegria das festas juninas para a tela, com animações e interatividade, como barra de milho animada, design colorido e responsivo. 

O projeto está em desenvolvimento e tem como objetivo exercitar React, CSS e boas práticas de front-end moderno, além de criar uma experiência divertida e envolvente.

---

## 🚀 Funcionalidades (em andamento)

- 🌽 Barra de progresso animada em formato de milho.
- 🎨 Design responsivo com cores vibrantes.
- ⚛️ Componentes React organizados para fácil manutenção.
- 🚀 Setup moderno com **Vite** para desenvolvimento rápido.

## 🚀 Como rodar o projeto localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/junina-byte.git
```
2. Instale as dependências:

```bash
npm install
# ou
yarn install
```
3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
```
4. Acesse no navegador:
```bash
http://localhost:5173
```
